**이음 (Round 1):** 수정 요청 6건입니다. 우선순위 순입니다.

**(1) 전제 수정 — "확장 배경" 섹션**

현재: `클라우드 멤버 → 파일 시스템 접근 불가`
실측: 데스크톱 앱 브릿지로 **읽기·쓰기 가능**. 이 파일이 그 증거입니다.

정확한 제약은 셋입니다.
- 사람이 대화창을 열어야 시작됨 (무인 트리거 불가)
- 폴더 접근 승인 필요 (세션 단위, 매번)
- 세션이 쉬면 컨테이너 회수 → 장시간 대기 루프 불가

따라서 "불가"가 아니라 **"수동 참여 가능 · 자동 루프 불가"** 로 고쳐야 Phase 1의 필요성이 정확히 서술됩니다. 지금 문장대로면 "브릿지가 없으면 아무것도 못 한다"로 읽히는데, 실제로는 "브릿지가 없으면 무인으로 못 돈다"입니다.

**(2) Phase 1 구현 방식 변경 — 가장 중요**

체크리스트의 `Claude API 호출`을 **headless 세션 호출**로 바꿀 것을 제안합니다.

단순 API 호출로 들어온 이음에게는 도구가 없습니다. 오늘 한 작업을 그대로 예로 듭니다 — FAMA의 타이포그래피 가이드를 라이트/다크로 렌더링해 팔레트 결함을 찾고, 하트 곡선 수식을 수치로 풀어 설명이 반대임을 확인하고, 로고 PNG의 알파 채널을 열어 전 픽셀 불투명임을 확인했습니다. 셋 다 API 응답만으로는 불가능합니다.

이음의 역할이 정합성 점검인데 검증 수단 없이 참여하면, 토론에는 들어오지만 역할은 수행하지 못합니다. headless 세션으로 호출하면 도구가 붙고 `bridge.sh` 분량도 비슷합니다.

차선책: bridge는 그대로 두되 **"검증 필요" 항목은 별도 세션으로 에스컬레이션**하는 분기를 넣는 것. 어느 쪽이든 "의견만 내는 이음"이 검증한 것처럼 기록되는 상황은 막아야 합니다.

**(3) External에게 [BLOCK] 권한 부여**

[AGREED] 권한을 주지 않는 설계는 맞습니다. 다만 구멍이 있습니다 — External이 "이 수치는 검증되지 않았다"고 지적해도, 로컬 멤버 둘이 합의하면 그대로 통과합니다. 안전 지적은 참고의견이 아니라 거부권이 필요한 종류입니다.

제안: 합의 권한은 계속 막되, **[BLOCK] 플래그는 허용**. External이 올리면 자동 [AGREED]가 막히고 의장 또는 CEO가 해소해야 진행. 구현은 분기 하나이고, 기자회견처럼 외부 노출이 있는 자리에서 검증 안 된 수치가 통과하는 경로를 막습니다.

**(4) `<!-- external-unverified -->` → 보이는 표기 병행**

HTML 주석은 마크다운으로 렌더링하면 사라집니다. 기자회견에서 회의록을 빔으로 띄우면 **미검증 발언이 검증된 것처럼 보입니다.**

주석은 기계 판독용으로 유지하고, 사람 눈에 보이는 표기를 함께 넣을 것:
```
> ⚠ External · 미검증 — 이 발언은 도구 검증을 거치지 않았습니다
```

**(5) Phase 2와 Phase 3의 관계 재서술**

현재 문서는 2 → 3 순차로 읽힙니다. 그러면 bridge → git 동기화 → API 이관으로 같은 기능을 세 번 만듭니다.

**Phase 3는 Phase 2를 대체하는 게 아니라 위에 얹는 것**으로 적을 것을 제안합니다 — Railway API가 최종적으로 git에 커밋하는 구조. 지자체·기관은 "서버 하나 더"보다 "레포에 기록이 남는다"를 신뢰하므로, 감사추적 계층은 Phase 2에서 만든 git에 그대로 두는 편이 유리합니다. Phase 3가 더하는 것은 실시간성과 플랫폼 중립성이지 저장소 교체가 아닙니다.

**(6) 운영상 3건**

- `cowork/이음/bridge-persona.md` — 한글 폴더명. Git Bash · Windows · git 조합에서 경로 인코딩 문제가 납니다(`core.quotepath`). `cowork/eum/`, `cowork/moru/` 권장.
- `ANTHROPIC_API_KEY` — Phase 2에서 토론 파일을 레포에 올릴 때 키가 함께 올라가는 사고가 흔합니다. `.gitignore` 등록을 Phase 1 체크리스트에 넣을 것.
- 기자회견 시연 인원 — 시연에 들어가는 건 로컬 4명(KODA·TRANG·FAMA·LUNA)이고 이음·모루는 Phase 1 이전이라 참여 불가입니다. 팀을 6명으로 소개한 뒤 화면에 4명만 나오면 질문이 나옵니다. 보도자료·발표자료에 "오늘 시연은 로컬 4인" 한 줄을 넣거나, 시연 전 소개를 4명으로 맞출 것.
